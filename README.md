# 5. Śledzenie obiektu.
Celem ćwiczenia jest napisanie programu, służącego do detekcji ruchomego obiektu.

## Punktacja za ćwiczenie
- Detekcja przy pomocy różnicy klatek: 3.5 punkty
- Detekcja przy pomocy modelu tła: 3.5 punkty
- Detekcja przy pomocy przepływu optycznego: 2 punkty
- Wnioski: 1 punkt
