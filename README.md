# 5. Śledzenie obiektu.
Celem ćwiczenia jest napisanie programu, służącego do śledzenia ruchomego obiektu.

## Punktacja za ćwiczenie
- Śledzenie przy pomocy różnicy klatek: 3.5 punkty
- Śledzenie przy pomocy modelu tła: 3.5 punkty
- Śledzenie przy pomocy przepływu optycznego: 2 punkty
- Wnioski: 1 punkt
