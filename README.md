# 4. Skaner dokumentów.
Celem ćwiczenia jest napisanie programu, który będzie wykrywał gdzie znajduje się dokument, "prostował" go, a następnie czytał tekst przy pomocy OCRa.

## Punktacja za ćwiczenie
- Wykrywanie dokumentu: za każdą metodę 3 punkty
- Wyrównanie dokumentu: 2 punkty
- Użycie OCRa: 1 punkt
- Wnioski: 1 punkt
