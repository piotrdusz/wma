# 3. Wykrywanie znaków nakazu.
Celem ćwiczenia jest napisanie programu, który będzie wykrywał znaki nakazu, zaznaczał je na obrazie oraz wykonywał prostą klasyfikację.

## Punktacja za ćwiczenie
- Poprawne wykrycie co najmniej 80% znaków: 5 punktów.
- Poprawna klasyfikacja co najmniej 50% znaków: 3 punkty.
- Wysłanie swojego zdjęcia znaku: 1 punkt.
- Wnioski: 1 punkt.
